BLE 配网（替代 SerialTest）

先在设备上长按 BOOT 3 秒（不要按 RST），屏幕出现蓝牙标志后再点「扫描」。 不会弹出 Windows 蓝牙配对框（这是 BLE GATT，不是经典蓝牙配对）。 也不要在「系统设置 → 蓝牙」里找/配对 AgentDisplay；请只用本页扫描。 本机蓝牙需保持开启；若扫不到请刷新页面（需后端已重启加载 BLE 接口）。
