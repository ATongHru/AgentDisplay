# ESP-IDF Development Environment Setup

This document records how to install VS Code + ESP-IDF on Windows 10/11 for this project, and how to fix common startup/build errors.

---

## Path conventions

Replace placeholders with your actual paths:

| Placeholder | Meaning | Notes |
|-------------|---------|-------|
| `<IDF_ROOT>` | ESP-IDF install root | Prefer a non-system drive, e.g. an `Espressif` folder |
| `<PROJECT_ROOT>` | This repo root | Directory containing `main/` and `CMakeLists.txt` |
| `<VERSION>` | ESP-IDF version | This guide uses **5.4.2** |

Project files use **relative paths** from `<PROJECT_ROOT>`:

```
<PROJECT_ROOT>/
├── main/
├── .vscode/
├── build/              # build output (gitignored)
├── sdkconfig           # generated by set-target
├── docs/开发环境搭建.md
└── docs/dev-setup.en.md
```

ESP-IDF and toolchain layout (under `<IDF_ROOT>`, separate from the project):

```
<IDF_ROOT>/
├── .espressif/
│   └── <VERSION>/
│       └── esp-idf/          # ESP-IDF source
├── tools/                    # compiler, cmake, ninja, openocd, etc.
│   ├── eim_idf.json
│   └── Microsoft.v<VERSION>.PowerShell_profile.ps1
└── dist/                     # download cache
```

## 2. Installation

### 2.1 VS Code extension

- Marketplace: https://marketplace.visualstudio.com/items?itemName=espressif.esp-idf-extension

```powershell
code --install-extension espressif.esp-idf-extension
```

Docs:

- https://docs.espressif.com/projects/vscode-esp-idf-extension/en/latest/installation.html
- https://docs.espressif.com/projects/vscode-esp-idf-extension/en/latest/troubleshooting.html

### 2.2 EIM (ESP-IDF Installation Manager)

```powershell
winget install Espressif.EIM-CLI --accept-package-agreements --accept-source-agreements
```

- CLI reference: https://docs.espressif.com/projects/idf-im-ui/en/latest/cli_commands.html
- Custom path FAQ: https://docs.espressif.com/projects/idf-im-ui/en/latest/faq.html

### 2.3 Install ESP-IDF to a custom directory (CLI, recommended)

Replace `<IDF_ROOT>` with your path:

```powershell
eim install `
  -p "<IDF_ROOT>/.espressif" `
  --tool-install-folder-name "<IDF_ROOT>/tools" `
  --tool-download-folder-name "<IDF_ROOT>/dist" `
  --activation-script-path-override "<IDF_ROOT>/tools" `
  --esp-idf-json-path "<IDF_ROOT>/tools" `
  -i v5.4.2 `
  -t esp32s3 `
  -n true `
  -a true `
  --pypi-mirror https://pypi.tuna.tsinghua.edu.cn/simple
```

| Source | URL |
|--------|-----|
| GitHub | https://github.com/espressif/esp-idf.git |
| China mirror (EIM) | https://git.espressif.com.cn/espressif/esp-idf.git |
| Toolchain mirror | https://dl.espressif.cn/github_assets |
| PyPI mirror (Tsinghua) | https://pypi.tuna.tsinghua.edu.cn/simple |

Verify:

```powershell
eim list --esp-idf-json-path "<IDF_ROOT>/tools"
eim select v5.4.2 --esp-idf-json-path "<IDF_ROOT>/tools"
```

### 2.4 Configure VS Code

In `<PROJECT_ROOT>/.vscode/settings.json`:

```json
{
  "idf.eimIdfJsonPath": "<IDF_ROOT>/tools/eim_idf.json",
  "idf.currentSetup": "<id from eim_idf.json idfInstalled[].id>"
}
```

> `idf.currentSetup` is the **id** field in `eim_idf.json`, **not** `IDF_PATH`.

In VS Code:

1. `Ctrl+Shift+P` → **ESP-IDF: Select Current ESP-IDF Version** → `v5.4.2`
2. `Ctrl+Shift+P` → **ESP-IDF: Doctor Command**

### 2.5 Initialize and build

```powershell
. <IDF_ROOT>/tools/Microsoft.v5.4.2.PowerShell_profile.ps1

cd <PROJECT_ROOT>
idf.py set-target esp32s3
idf.py build
```

Or use the project wrapper on Git Bash:

```bat
scripts\idf_build.bat build
```

## 3. Common errors and fixes

### Error 1: OpenOCD error monitor init failed

```
Error initializing OpenOCD error monitor: Cannot convert undefined or null to object
```

**Fix:**

1. Run `idf.py set-target esp32s3` in `<PROJECT_ROOT>` to generate `sdkconfig`
2. Set correct `idf.eimIdfJsonPath` and `idf.currentSetup` in `.vscode/settings.json`
3. **Remove** incomplete `idf.customExtraVars` so EIM injects full PATH

---

### Error 2: CMake / Ninja not found in VS Code build

```
CMake or Ninja executables not found
```

**Cause:** `idf.customExtraVars` overwrote PATH without cmake/ninja.

**Fix:** Remove `idf.customExtraVars`; keep only:

```json
{
  "idf.eimIdfJsonPath": "<IDF_ROOT>/tools/eim_idf.json",
  "idf.currentSetup": "<your setup id>"
}
```

Reload VS Code. PowerShell CLI builds usually work because the activation script sets PATH.

---

### Error 3: Doctor reports missing sdkconfig / launch.json / c_cpp_properties.json

| File | Fix |
|------|-----|
| `sdkconfig` | `idf.py set-target esp32s3` |
| `.vscode/launch.json` | Create from extension template |
| `.vscode/c_cpp_properties.json` | Create from extension template |

Template path: `%USERPROFILE%\.vscode\extensions\espressif.esp-idf-extension-<version>\templates\.vscode\`

---

### Error 4: Toolchain incomplete — gcc cannot find cc1

```
xtensa-esp-elf-gcc.exe: fatal error: cannot execute 'cc1'
```

**Cause:** EIM zip extraction failed.

**Fix:** Re-extract manually (adjust version paths):

```powershell
$root = "<IDF_ROOT>"
$ver  = "esp-14.2.0_20241119"

Remove-Item -Recurse -Force "$root/tools/xtensa-esp-elf/$ver"
New-Item -ItemType Directory -Force -Path "$root/tools/xtensa-esp-elf/$ver"
Expand-Archive -Path "$root/dist/xtensa-esp-elf-14.2.0_20241119-x86_64-w64-mingw32.zip" `
  -DestinationPath "$root/tools/xtensa-esp-elf/$ver" -Force
```

Verify `cc1.exe` under `xtensa-esp-elf/.../libexec/gcc/.../`.

---

### Error 5: `idf.py` does nothing in Git Bash

ESP-IDF v5.4+ skips `main()` when `MSYSTEM` is set (Git Bash).

**Fix:** Use **PowerShell** for `idf.py`, or:

```powershell
Remove-Item Env:MSYSTEM -ErrorAction SilentlyContinue
$idf = "<IDF_ROOT>/.espressif/<VERSION>/esp-idf"
$py  = "<IDF_ROOT>/tools/python/v5.4.2/venv/Scripts/python.exe"
& $py "$idf/tools/idf.py" build
```

---

### Error 6: Wrong `idf.currentSetup`

Do **not** use `IDF_PATH` as the value. Use `idfInstalled[].id` from `eim_idf.json`:

```powershell
Get-Content "<IDF_ROOT>/tools/eim_idf.json" | Select-String '"id"'
```

---

### Error 7: EIM GUI wizard defaults to C:\esp

Cancel the wizard and use CLI `eim install` from §2.3 for a custom drive.

## 4. Daily commands

```powershell
# Activate environment (each new PowerShell window)
. <IDF_ROOT>/tools/Microsoft.v5.4.2.PowerShell_profile.ps1

cd <PROJECT_ROOT>
idf.py build
idf.py -p COMx flash monitor

eim list --esp-idf-json-path "<IDF_ROOT>/tools"
```

Flash font and animations separately:

```bat
python scripts/flash_font.py -p COMx
python scripts/flash_animations.py -p COMx
```

---

## 5. Notes

1. **Use PowerShell**, not Git Bash, for `idf.py`.
2. **Avoid manual `idf.customExtraVars`** unless you provide full PATH.
3. Python venv warnings in Doctor are usually harmless.
4. **ESP-ADF Path undefined** — ignore if not using ESP-ADF.
5. **OpenOCD warnings** — safe to ignore for UART flash-only workflows.
6. Keep the repo path free of spaces and non-ASCII characters.
